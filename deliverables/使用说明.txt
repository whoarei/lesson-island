课文岛 · Lesson Island 0.3.0
Android 包名：top.mossmoss.lessonisland

1. 从 GitHub Release v0.3.0 下载 LessonIsland-0.3.0.apk 并安装。要求 Android 8.0 及以上。
   https://github.com/whoarei/lesson-island/releases/tag/v0.3.0
   仓库已公开，下载无需 GitHub 账号。
2. 首次安装没有预设课程。首页点击「家长创建课程」即可开始，也可从右上角「家长入口」进入。
3. 首次进入时由家长设置自己的 4 位 PIN。验证后直接进入课程制作页面。
4. 在家长设置中直接填写 API 地址、模型、密钥和语音配置，可分别测试模型连接和语音试听。
   已保存的密钥不回显，留空保存会保留原密钥；小眼睛只显示本次新输入的内容。
5. 制作新课：家长首页或课程工作台 → 创建课程 → 按顺序选图 → 识别生成 → 校对原图、句子、翻译、词汇与理解题 → 补全音频 → 勾选校对确认 → 发布。未配置 API 时，制课页有「配置制课服务」入口。
   句子和重点素材可重新生成音频或直接录音；试听后保存生效，取消会保留原音频。
   已发布课文再次编辑时自动建立带日期的新草稿。课程工作台可选择、继续编辑和管理多个草稿；
   发布后保留其他草稿、历史版本及旧版学习记录。
6. 学生在学习岛中依次完成六关；复习站自动安排错题与间隔复习。
   各课文、今日复习和错题复习分别保存断点，直接进入即可续上；重练旧关卡不覆盖正式学习进度。
   今日小目标累计闯关、复习、自由重练与素材阅读的实际前台时长，未完成也计入，进入后台暂停。
7. 家长在学习概览查看完成情况、正确率、时长和薄弱内容。
8. 更换设备或卸载前，请先在家长设置导出 ZIP 备份。备份包含课程、原图、音频、草稿关联和学习记录，
   不包含 API 密钥和家长 PIN；新设备需要重新配置这些内容。
9. 家长设置 → 应用更新，可手动检查新版，默认每天在进入家长模式时自动检查一次，也可关闭。
   下载后校验安装包并打开系统安装器，安装仍需用户确认；首次可能需要允许课文岛安装更新。
   0.2.0 没有内置更新入口，请先手动安装 0.3.0，此后可使用应用内更新。

课程素材.zip 内含逐句中英文本、词汇/短语/重点句子、MP3 和素材索引，供单独查阅。它不是软件“导入备份”按钮使用的格式。

工程中的示例素材仅供调试，不随正式应用安装。升级后会自动归档原先误导入且未修改的示例课程，自建课程及其进度会保留。

新的课程制作需要联网，已下载课程可离线学习。API 密钥在本机加密保存，不在 APK、课程素材或源码包中。
完整构建、测试和维护说明见项目 README.md。

旧版包名 com.textisland.app 与新版属于不同应用。如有旧版学习数据，请先从旧版导出 ZIP 备份，再导入新版。API 配置与家长 PIN 需重新设置。

0.3.0 使用原用户证书签名，可覆盖升级同一证书的 0.1.x / 0.2.0。GitHub Actions 使用仓库 Secrets 生成正式签名包，
Release 同时提供 LessonIsland-0.3.0-source.zip、update.json 和 SHA256SUMS.txt。Actions 中标有 unsigned 的检查包不能直接安装。
历史测试说明保留原版本标识，0.3.0 的构建与发布结果以 v0.3.0 对应 Actions 运行记录为准。
本地签名配置仍为 .local/signing.properties；keystore、签名密码、别名和用户 API 密钥不进入源码包。
