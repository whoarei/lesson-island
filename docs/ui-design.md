# 课文岛界面设计

这次改版围绕「和芽芽一起探索课文岛」展开。参考多邻国的[圆润造型与插画语言](https://blog.duolingo.com/shape-language-duolingos-art-style/)和[学习路线设计说明](https://blog.duolingo.com/new-duolingo-home-screen-design/)，在课文岛中使用自己绘制的角色、图标和学习情境。

## 视觉与交互

- 原创角色「芽芽」是一只捧着书、头顶嫩芽的小海龟。欢迎、思考和庆祝三种表情贯穿首次使用、学习、复习和成长页。
- 使用天空蓝、嫩叶绿、暖黄和淡紫的色块，搭配深色正文、圆角和明确的标题字重。主要按钮有实色底边和按下状态。
- 学习岛卡片整块可点击。六个关卡由弯曲的虚线路径连接，已完成为金色、当前可学为嫩绿、尚未解锁为带锁的灰色路标；状态同时通过图案和文字表达。
- 学习时把「检查答案」「检查拼写」「继续」固定在底部，长句和词块可在其上方滚动。正确反馈庆祝，错误反馈解释并鼓励重试。
- 复习页以记忆花园呈现到期数量和错题入口。成长页保留真实 XP、学习时间与记录，并展示「初次出发」「点亮一座岛」「三日足迹」三项里程碑。
- 家长端沿用统一字体、按钮与卡片，保持创建、校对、发布和配置操作清晰。空课程首页将「家长创建课程」固定在底部，大字体下也无需滚动寻找入口。

## 实现约束

插画、路标、图标和进度条用原生 Canvas / VectorDrawable 绘制；无图片下载、无新增运行时依赖。主要触控目标至少 48dp，文字支持系统字体缩放，地图和词块按容器实际宽度布局。欢迎动画播放约一秒后停止，尊重系统禁用动画设置；离开页面后释放动画。

课程、关卡、经验和复习规则沿用已有逻辑。徽章按已有记录计算，不增加虚构奖励、生命值或付费入口。示例课程仅用于 instrumentation 测试，正式应用首次安装仍为空课程。

普通开发构建不递增版本，也不覆盖 `deliverables` 中已发布的安装包。模拟器验证日志和截图保存在未纳入 Git 的 `test-results` 目录。
